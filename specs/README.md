# specs/

Per-feature specs and implementation plans go here.

## Naming

`NNN-short-slug.md` — e.g. `001-auth-tenancy.md`, `002-daily-shed-log.md`

## When to add

Before a non-trivial slice (auth, daily ops, analytics). Keep the file focused: goal, acceptance checks, files likely touched, out of scope.

Agents should link the active spec from `MEMORY.md` while working that slice.
