# 007 — Hen-day % + shed/farm compare

Design: [docs/superpowers/specs/2026-10-01-poultry-saas-product-design.md](../docs/superpowers/specs/2026-10-01-poultry-saas-product-design.md)

## Slice

Dashboard KPIs include **hen-day %** = `100 × eggs_period ÷ (live_birds × days_in_range)` using current live birds (null when birds are 0). Same formula per shed and per accessible farm for compare tables on the Owner dashboard for the selected range.

## Out of this slice

Alerts, money, historical bird series for hen-day.
